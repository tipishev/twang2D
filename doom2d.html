    Hardware note

    This build adds five arcade buttons to the Twang 2D hardware: Fire, Use, Strafe, Weapon and Map. The Matrix Portal S3 has few free pins, so wire the buttons to an MCP23017 I2C GPIO expander on the same I2C bus as the IMU.
